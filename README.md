# Salon Ria Landing Page

Landing page resmi untuk Salon Ria, salon kecantikan profesional di Tangerang.

## Setup

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## SEO

- Metadata lengkap dengan OpenGraph
- Sitemap XML otomatis
- Robots.txt teroptimasi
- Struktur semantic HTML
- Responsive & mobile-first
- Lighthouse ready
