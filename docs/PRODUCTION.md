## Deploy ke Production

### Opsi 1: Vercel (Recommended)
```bash
npm install -g vercel
vercel --prod
```

### Opsi 2: Netlify
1. Buat account di netlify.com
2. Drag-drop folder ini
3. Auto-deploy dengan HTTPS

### Opsi 3: Shared Hosting
1. FTP upload ke `public_html/`
2. Setup domain nameservers
3. Enable SSL (gratis dari provider)

## Contact Form Integration

Pilih satu backend:

**Formspree** (easiest):
```html
<form action="https://formspree.io/f/YOUR_FORM_ID" method="POST">
```

**Firebase** (free tier):
Setup di Firebase Console, copy config

**Custom API** (full control):
Buat endpoint POST /api/contact
